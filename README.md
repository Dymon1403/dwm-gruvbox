## HOW TO INSTALL????

1. **Clone the repository:**
```bash
    git clone https://github.com/Dymon1403/dwm-gruvbox.git
    cd dwm-gruvbox
    chmod +x install.sh

```

 2. **Run the script:**
```bash

   ./install.sh

```

3. **How to run:**
        Add exec dwm in your ~/.xinitrc and launch X11:
```bash
startx
```
**Notes**

To run dwm, it is recommended to use xinit / startx.
