**How to run:**
Clone repo and replace my repo in ur dwm/

Add exec dwm in your ~/.xinitrc and launch X11:
```bash
startx
```
**Notes**
you need:
gcc/clang 
make
pkg-config
libX11-devel
libXft-devel
libXinerama-devel
dmenu
alacritty
flameshot

To run dwm, it is recommended to use xinit / startx.
